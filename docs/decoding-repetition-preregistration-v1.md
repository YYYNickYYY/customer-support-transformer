## 1. 假设与唯一因素

假设：回复内禁止重复的连续 **4 个冻结 BPE token ID**，可能减少逐字重复，但未必减少语义重复，也可能破坏必要实体复现、步骤或句子。先检验，不默认采用。

A：原 greedy，`no_repeat_ngram_size=0`。B：同一 greedy，`no_repeat_ngram_size=4`。只有这个设置改变；不叠加 repetition_penalty、采样、实体豁免、后处理、长度调整或话术替换。选择 4 是诊断此前观测到的 4-token 重现，不是已验证的最优值；此次不搜索 2/3/5 等参数。实体感知方案如有必要另行预登记，不在看见 B 失败后偷偷加入。

固定第五实际 `best.pt`、冻结 tokenizer 与输入模板（BOS USER instruction ASSISTANT）、CPU/2线程/seed42、上下文512、新token320（含EOS），角色屏蔽 PAD/BOS/USER/ASSISTANT。model.eval、no_grad，无参考回复输入，无 optimizer。
第五模型训练源为 v3.1，未训练后来退款 v1.2；此对照不检验新清单训练效果。

## 2. 可复现算法契约（待实现）

每步先读取未屏蔽 logits，要求全为有限数；按原生成器屏蔽四个角色 token。仅对**本次已生成回复 token**构造历史四元组，不包含 prompt。已生成不足3个时无额外屏蔽；否则取末3个 ID 为前缀，凡历史四元组具有同样前缀，屏蔽其第4个 ID（置负无穷）。历史窗口重叠计入，大小写和空白不另归一化。

EOS 始终不受 ngram 屏蔽；不得因其它 token 被屏蔽强迫插入 EOS。对剩余 logits greedy argmax，平局选择最小 token ID，与原 torch.argmax 对齐。理论上有限 EOS 确保有可选项；若实现仍出现无有限候选，应报错并标本条失败，不放松约束、随机抽样或填补回复。

追加选中 token 后，依次检查 EOS、总长512；否则至320次停止。解码与原 tokenizer 保持一致。不为保留实体偷偷豁免 ngram，不为改善语言删句。保存每步原 greedy 第一候选、屏蔽集合、实际选中 ID、是否约束生效、EOS 排名与停止原因，便于解释副作用。
