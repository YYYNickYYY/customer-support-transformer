# 正确监督样本的条件利用诊断：预登记 v1

## 固定选样，不看新生成结果

仅从已经完成的训练输入—目标审计48对中选。候选ID末尾按下面清单冻结：部分商品1256/1298/1469/1568/1584/1607/1698/1709；整单取消378/435/443/460/612/824/969；退款申请16597/16831/16867；退款资格6365/6461/6666/6688。来自已复核aligned行；排除104含混输入、734未说明具体问题和编号/否定覆盖诊断。

每类按SHA256(`condition-use-v1:42:<family>:<完整ID>`)排序取2，原始ID作平局顺序。每类两行不是独立模板数保证，不补样、不改选样。排名同位的部分/整单、申请/资格构成4对。选定8条原始训练问题，各加1条预写等义表达，合计16次；另重复首条原始问题一次，17次生成。改述文本随代码冻结，在看到生成前固定，不添替代诉求；保留订单字段和单/复数范围。若两行改述相同，视为重复刺激而非独立能力证据。

先冻结协议、计划/原始完整输入目标、实现/单测、第五权重、tokenizer、配置、既有审计及运行环境，后生成。仅使用此前第五诊断冻结的generation配置，不把configs/generation.json旧checkpoint当第五模型。CPU2线程、seed42、greedy、角色token屏蔽、EOS不屏蔽、context512、new320、no_repeat_ngram_size0。只向模型提供问题，绝不把参考目标或intent标签拼进生成prompt。

## 两类互补观察

1. **自由生成任务匹配**：对每条原始/改述全文AI判断action_match、实际动作及原文证据；部分商品必须逐商品操作或询问待删商品，不得整单取消/发票下载。整单取消必须取消路径或相关必要澄清，不能改成部分商品。申请退款必须申请渠道/步骤/相关购买信息澄清，不能只列资格；资格必须解释/指向可退情形或相关资格澄清，不能仅索取申请资料替代。混合回复按全文是否有效满足客户主任务判断，开场主题正确但随后转无关路径不能通过。政策内容伴随有效申请路径不自动失败。另记重复/风险/实体/通顺的观察旁注，不与135dev分数或因素表混算。本组不是新模型评价基准。
2. **固定目标条件对照**：仅对8条原始来源目标，各在自己的问题与配对的相反任务问题下teacher-force打分。两种输入均为实际训练问题，不删除输入或引入随机噪声。同一个目标只取两个prompt都能容纳的同一token前缀，max_length512、同一标签数、只计目标及保留EOS。记录两边NLL与差值`swapped_nll - matched_nll`（正值表示该目标在自身条件下更受偏好）。EOS仅原始目标完全保留时计入，不给截断前缀伪造EOS；若零监督则停止。保存完整目标长度、保留长度、丢弃长度、EOS、原训练512下保留长度，避免把存储全文等同监督可见全文。

teacher forcing让模型看见正确回复历史，因此与自回归自由生成有本质区别；相同目标不同prompt还改变位置/长度，不是纯单token因果干预。差值不设事后通过阈值，不以微小差异、top5概率或文本不同证明理解；无总体accuracy、无显著性/因果声明。两方向都报告，不挑差值有利者。这里预登记交换已正确任务问题的对照，不同时做遮蔽、词打乱或参数试验。

## 判定和失败处理

原始8/改述8分别报告每类n=2及各4对双方是否匹配；一组改述稳定通过须同来源原始与改述都任务正确，不能都答错当稳定成功。同输入重复必须token/正文/停止一致，否则批次无效。语义判定逐条全文阅读，不由关键词脚本打分；待评为pending而非0。AI已知原诊断上下文，非独立盲评。

记录EOS/context/new上限；错任务发生在截断前时不归因长度。生成前检查模型训练配置、tokenizer revision和源审计冻结；结束验证权重不变/梯度None/optimizer_updates0及冻结依赖不变。创建式写入独立outputs/condition-use-20261006-v1，部分完成可在完全相同哈希下补缺，冲突/损坏报错，不覆盖历史产物。
