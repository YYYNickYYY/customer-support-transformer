## 结论与下一步

模型**并非完全不受问题影响**：同目标条件偏好及整单/资格任务响应都显示局部条件利用。但它没有稳定保留细粒度动作范围；正确训练问题本身也会出现“开头知道删商品、正文滑向取消模板”，因此不能只归为陌生表达或未见监督。

不立即第六次训练，也不改学习率/轮数或逐条修回复。下一步建议另行预登记一个明确机制问题：**在相同问题下，模型的任务偏好是否随回复前缀变弱或转向？** 通过预先固定、同类配对的正确/中性回复前缀条件，观察关键动作分支的概率与续写，不用这些坏句子反复试参数。该后续仅是建议，本轮未实施；不能把当前证据直接解释为已证明“回复历史压过问题”、某注意力头失效或解码算法为唯一原因。

本轮完成全文AI判读，非独立盲评/多人一致性；训练原问题成绩不是dev泛化成绩。所有输入、完整目标、改述、配对、NLL与旁注可查，历史因素表/风险v1.1评分不回写。未读取dev/sealed_test、未推送GitHub。
