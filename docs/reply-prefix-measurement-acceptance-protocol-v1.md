2026-10-06。仅验收现有方法，**不重跑第五模型生成或分支推理，不改冻结实验，不训练/调参/补话术**。新增独立验收证据与合成单测，不把测试通过等同业务测量有效。

顺序：冻结本标准、验收实现/单测及前轮计划/协议/结果/冻结文件，再检查现有产物与冻结tokenizer。允许小型合成模型验证标签/概率计算，不加载第五权重到模型。输出独立目录outputs/reply-prefix-measurement-acceptance-20261006-v1，不读取dev/sealed_test正文、不改表格/配置/历史分数。

## 分开验收四层

1. **可追溯和执行契约**：所有已声明来源/产物哈希、8基线一致、同输入重复、25完整记录、前缀计入320预算、不补EOS、不泄露参考答案；缺失/冲突为fail，不覆盖文件。
2. **算术契约**：用独立位置相关合成oracle逐步next-token概率核查branch_nll的首标签、全部标签、总/平均NLL、问题/前缀不参与loss；用下三角合成模型测试分支未来token不改变更早token概率。独立重算所有已保存margin/S、汇总、缺失分母。仅一致性校验，不重算第五logits，不能证明保存的模型概率来源绝对真实。
3. **刺激/边界契约**：现有人工前缀不得以独立空白token、半个UTF8字符或保留控制token结束；decode须与原文本相符。只做tokenizer inspection，保存末尾token/字符和症状。将既有完整回复按训练分词方式整体重编码，检查人工前缀是否仍是完整回复token序列的前缀，作为正常训练表示衔接的附加检查；模型生成ID不必是canonical BPE，故非等价不算生成器实现错误。真轨迹句末契约不得把列表编号当完整语义句末；原记录全部保留，报告违规位置，不删除后重算有利汇总。问题/候选长度与保留完整性逐项记录。
4. **构念与因果契约**：若要称为业务“任务偏好”，应有上下文适合的成对真实行动分支、与独立全文任务判断交叉验证；候选长度/说法差异须受控。不能把任意候选句的平均NLL差直接当业务概率/准确率。正确完整回复也出现负margin时，记录反例但不把它自动算测量分类错误：当前探针未定义每阶段真实下一句的金标准。真实自轨迹观察不是随机历史干预，不能用于历史致遗忘因果结论；人工干预若边界契约失败，因果验收fail。

每层使用pass/fail/not_established，分别给证据；可复现、算术正确并不抵消构念未验收。总体“可用于任务机制/训练因素决策”的验收必须四层均pass；否则保留当前结果为探索性/数值观察，不推荐生产前缀或第六次因素。
