# 条件利用测量 v2：方法验收结论

日期：2026-10-06。对应[唯一预登记协议](condition-use-measurement-v2-protocol.md)及[方法单测](../tests/test_condition_use_measurement_v2.py)。

## 结论

**通过有限用途的方法验收：可以研究“共享完整中性历史下，指定行动句的条件敏感性”。未通过作为真实业务理解、唯一下一行动选择或历史导致遗忘的测量。**

本轮只加载冻结 tokenizer、读取来源清单及校验文件哈希，使用新建的合成因果 oracle。**未加载第五 checkpoint 到模型，未执行第五模型的新 forward/生成，未训练、调参或修改目标。** 没有新增 Excel 或 outputs 目录；这不是第五模型测量结果。

### 固定长度明细

| 对照 | 说法1 a/b | 说法2 a/b | 说法3 a/b |
| --- | --- | --- | --- |
| 部分/整单 | 10/11 | 11/9 | 11/12 |
| 申请/资格 | 12/13 | 11/11 | 13/13 |

四对问题 token 长度分别为 13/9、12/9、7/11、10/11。共享历史相同不意味着分支绝对位置相同；v2明确只描述整个问题条件的数值变化，不能隔离问题语义与位置效应。

H0 下候选保留一个前导空格以保持同一候选 token 序列；它随首词编码而非独立空白历史。此风格设定固定、双方相同，但H0不等于所有真实自由回复开场，不能泛化为无历史真实业务选择。

## 语义审查的关键边界

中性历史未指向任务，且所有阶段尚未做业务动作，所以不存在v1的“任务已经回答完，再把旧分支强塞到后文”解释。但人工历史仍不是模型自然生成历史，不能据阶段差称模型遗忘。

三组行动都只是寻找相关选项/步骤/条件，不虚构系统权限或退款条款；合理但帮助有限。退款申请有时合法需要先查资格，所以申请/资格候选不是业务上互斥的唯一答案。候选NLL不能代替完整续写评审：需另记行动方向、是否服务于请求、全文是否落实。无法区分时记 unavailable，而不是关键词命中就判冲突或通过。

本轮内容审查者与协议作者为同一AI，知道旧诊断上下文。不能宣称独立语义验证已通过，也不以这些合成边界例子计算模型正确率。
