## 具体发现

1. **没有发现标签错一位或把前缀算进loss。** 原先均匀logits测试不足以发现所有错位，因此新增独立非均匀oracle：逐个目标token以当时问题+前缀+过去目标计算log-sum-exp，与生产函数全部标签、总和和均值逐项比较；另测试更改分支未来token不影响首目标概率。这里是合成算术检查，不是第五模型的业务验证。

2. **末尾空格合法，但作为人工历史的刺激边界未验收。** 所有17非empty记录prefix末尾piece为Ġ并可准确解码回原文本。将完整回复按训练方式整体重编码，只有1个记录的人工前缀不再与完整编码的开头匹配；因此不能把全部异常笼统称为“BPE拼接错误”。自回归输出不必等于canonical整体分词，非等价也不自动说明生成器实现错误。独立空白、罕见人造开场、语义提示、长度/位置都可能影响续写；没有针对性对照，不能认定空格是唯一原因。原生成普遍碎词/残缺字段仍是拒绝干净语义归因的实际限制。

3. **标点边界不等于句子边界。** 固定32/64/96阈值后取首个句末标点的实现会把1./2.当结束。5条违规位置保留在ledger，不删除、不回算一个“更漂亮”的S。它们违反“完整语义句末”的解释契约，但不表示脚本漏记录或事后挑样。

4. **分支mean NLL不是业务概率。** 部分/整单候选12/13 token；申请/资格13/15 token。除长度外，一个是索要信息、另一个是确认操作或陈述政策，风格不同。平均归一化没有消除这些差异；总NLL与均值回答不同问题。相同候选在两个问题下的S有清楚的数值定义，可以报告为“这两个句子的条件敏感性”，但不能直接换名“真实任务偏好”。

5. **4条记录构成解释反例。** 完整资格6461在64/96、资格6688在96，以及申请16597在96均任务通过而自任务margin负。这并非自动证明4个测量分类错误，因为当前根本没有定义每阶段正确下一句的金标准；有些回复已经解释完主要任务，继续强塞某个探针句可能不自然。它说明不能使用margin正负自动评业务正确，不能把后期负值当遗忘证据。完整回复的AI判读也不是独立人工金标准。

## 允许保留的结论

旧结果保留为**指定候选句的数值观察**：31可用阶段的S为正，23个后续阶段比对应0阶段低，非单调；不能升级成业务准确率、实际任务遗忘或模板压倒问题的因果结论。B组任务旁注仅探索性，不据它采用强制开场策略或决定第六次训练。
