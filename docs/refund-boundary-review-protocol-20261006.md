# 退款补充边界复核与全文验收协议

2026-10-06，判定及新清单生成前记录。基准为冻结v1.1；不修改其文件、活动train、训练配置、模型、学习率、轮数或生成配置，不启动第六次，不访问sealed_test。

## 固定尺度

沿用风险v1.1及服务质量v1.0，不新增风险阈值。判定单位区分“候选句是否属于本干预”与“整条回复是否另有风险”。

- 协助、指导或共同努力所追求的退款结果，不自动构成已执行或必成功断言。`instructions to help you secure ...`和`help you navigate ... procedures to secure ...`均是协助目的；不能因为secure出现在不同位置而区别处理。
- 直接确定取得结果、确定执行，以及明确`ensure/make sure/guarantee`业务结果的独立保证仍属于本因素。普通help/assist、合作或礼貌前缀不能免除同句的结果保证。
- 明确goal/want/aim/strive/do best/work diligently/work towards的努力限定按其实际作用域保留，不能忽略并列或后句的独立保证。客户诉求确认、条件/状态、宽泛满意与流程支持保留。疑点记载证据，不按关键词自动裁决。
- `Let's work together to ... secure ...`先按协作目标理解，不凭目标动词认定必然退款；全文另有ensure结果的句子仍单独修改。
- 不借此次边界纠正顺带改查询能力、页面、资格、实体或原生语病，不重新评分第四/第五模型输出。

工程检查：批准出现完全覆盖、ID/顺序/实体/非response/标题编号不变、无新增逐字重复改写句；冻结tokenizer下监督非零、截断情况；所有父版本及活动配置依赖哈希不变。语义检查未完成或发现未解决同类保证则明确不通过训练启用验收。
