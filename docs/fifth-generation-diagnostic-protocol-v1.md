# 第五次模型独立生成诊断协议 v1

2026-10-06，在新推理前冻结。目的：观察已有模型的保证话术组合、重复和停止行为，不验证未训练的退款清单，不优化解码或重评分。

## 固定来源与抽样

仅用第五次已完成run的best.pt，以及已有同135条dev输出、统一重复复核与风险v1.1评分。不读取sealed_test，不给模型参考回复，不训练、不回传梯度、不改旧代码/配置/评分/清单。

诊断病例不是无偏效果评估：

1. 纳入已经记录的3条退款保证病例16355、26320、26438。
2. 第四→第五重复0→1中，按SHA256(`fifth-generation-diagnostic-v1:42:new-repeat:ID`)、ID排序取2条。
3. 重复1→1中，按同规则（stratum=persistent-repeat）取2条。
4. 第五风险0且重复0中，按同规则（stratum=control）取3条作观察参照，非同intent匹配因果对照。
5. 纳入同135中全部非EOS停止样本，便于检查上限截断。按上述顺序去重，不为凑数替换，也不看新trace后换样。

选样只读取冻结旧ID、评分、stop_reason与问题；选样、源原文、模型及脚本SHA-256在推理前保存。

## 推理不变项

CPU、2线程、seed42，冻结tokenizer4000词、模板和上下文512。greedy，屏蔽PAD/BOS/USER/ASSISTANT，max_new_tokens320；EOS优先于上下文停止，无KV cache，与既有generate_reply契约相同。训练模式临时切eval后还原，torch.no_grad；记录torch/tokenizers版本。

新诊断循环只读logits，选择规则不变。每条新生成的token序列、正文、prompt长度和stop_reason须与既有记录精确一致。否则保留失败材料、停止解释，不把差异当改善。

## 记录字段与分析

- 每步：步号、输入长度、选中token/词表片段、屏蔽后top5概率与token、EOS概率/严格大于EOS的rank、top1与top2 logit差。记录的softmax是模型下一token条件分布，不是业务正确性或因果解释。
- 全token ID和最终文本、剩余上下文、结束原因，以及未变的checkpoint哈希。
- 既有专家原文证据定位到输出字符和token区间；重复按全文作用判断，不将4-token重现自动记为语义重复。token级重现仅作排查线索，已输出的冗余开头和结束点需明确。
- 上限样本只检查其末步EOS是否被屏蔽/是否为greedy首选及当时上下文余量，不延长生成，不尝试新温度/惩罚来挑更好回复。正常EOS样本检查不良片段发生在结束之前还是由截断造成。
- 保证/重复片段在第五实际训练目标中的逐字检索，仅说明是否文本重现；0不能证明没有语义来源，也不能把dev参考当对应train目标。

先复现再解释，逐病例记录保证/重复形成位置、已有上下文功能和EOS信息。没有activation/attention归因或反事实干预，不能仅凭概率轨迹证明某头、某训练样本或某因素的原因。

## 完成与退出

所有入选病例复现一致、trace检查通过、来源哈希不变后形成独立报告。报告区分确定观察、机制线索、尚需实验验证的假设；不宣布“纯模型原因”或v1.2效果已验证。本轮不授权第六次训练、扩大目标改写或改变超参数。
