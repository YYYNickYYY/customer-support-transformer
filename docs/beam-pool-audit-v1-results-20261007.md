# 第五模型：12条束搜索候选池审查

结论：**停止当前束搜索→诉求检查器路线，保留第五模型原 greedy 方案。** 束搜索代码保留作多路径搜索学习，不替换默认生成；不训练、不改参数、不追加规则。

## 固定条件与结果

从既有135条dev问题中，按问题文本资格过滤、固定盐值的ID哈希排序，每类取2条：取消订单、删除部分商品、开户、注销、退款申请、退款政策查询。未按本次输出挑选；部分删除病例1535曾在功能演示中出现，因此这不是全新盲测。协议在生成前冻结，见[预登记](beam-pool-audit-v1-protocol.md)。

固定第五best.pt、tokenizer及输入token、CPU/seed42、束宽4、返回4、长度归一化指数0.7、最多320个新token。共保存12条greedy和48条beam，含完整trace。权重逐张量不变，无梯度、无optimizer更新。

“可用”按冻结工程标准：意图2、帮助2、通顺至少1、风险0、实体问题0、无严重重复；允许轻微重复。这不是业务成功率，也不是总体质量估计。其余9个候选池并非全是诉求错误：也包括缺少可执行帮助、实体替换或风险导致不可用。

## 收益、代价与限制

- 病例4：greedy误取消整单，beam正确询问待删除商品；病例5：beam避免greedy虚构人物并保留账户类型。
- 病例3反向退步：greedy问待删除商品，四候选都转整单取消；病例8：greedy回应注销报错，四候选转注册报错。
- 重复标记greedy为8条，第一候选为6条；实体问题2→1。局部改善没有增加可用问题数，不据此换默认生成。
- 风险greedy及第一候选各1条；第三候选多出病例10的补偿结果保证。候选池不能只检查诉求而忽略风险。
- 束搜索有8条达到长度上限（两个政策问题的全部候选），greedy有1条；达到上限不必然不可用，病例11仍有完整有效的政策说明，但尾部断句降低通顺评分。
- 每题4候选文字均不完全相同，但多数行动路径相似。文字多样不等于诉求多样。

本次是非盲AI全文代评：风险v1.1，其他维度v1.0，已有模型历史背景；无独立人工复核，不作统计显著性或模型总体能力结论。固定小样本只支持本路线的预算决策，不证明所有束搜索或检查器无效。
