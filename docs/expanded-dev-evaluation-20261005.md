## 第五次唯一因素决策

建议基于第四次v2，只新增“退款执行／补救结果承诺的训练目标整句改写”：将未经后台核实的退款发放、付款完成和确定补救结果改为核查资格、协助申请或转官方支持。努力意愿与合理条件说明保留。查询准确性、现时隐私、订阅权益、实体、重复、截断留作其他独立因素，不顺带修改。

理由：退款风险三次均持续较高，且有可干预的训练残留证据，优先于改学习率或模型；准确估计也值得后续独立实验，不与退款同时改。

下一步先定义语义纳入/排除边界，在全train提名候选、全文审阅，记录ID/原句/替换整句/拒绝原因，检查语法和实体，再冻结v3。不要只挑当前dev对应例子，不复制dev答案进train。冻结后才创建第五次配置并按用户要求启动。保持5轮、学习率、batch、模型、tokenizer、seed、生成配置不变，仍用同135条对照，分别报告退款指标和其他intent副作用。本轮未改训练数据或配置。
